MMM-InfoCentral - Quick Testing URLs
================================================

TESTING WITHOUT PHYSICAL BUTTONS
--------------------------------

Browser Testing (Local):
http://localhost:8080/infocentral/button/next
http://localhost:8080/infocentral/button/return

Browser Testing (Remote - Replace IP):
http://192.168.1.100:8080/infocentral/button/next
http://192.168.1.100:8080/infocentral/button/return

PowerShell (Windows):
Invoke-WebRequest -Uri "http://localhost:8080/infocentral/button/next"
Invoke-WebRequest -Uri "http://localhost:8080/infocentral/button/return"

Bash (Linux/Mac/Raspberry Pi):
curl http://localhost:8080/infocentral/button/next
curl http://localhost:8080/infocentral/button/return

Web Remote Control:
Open: modules/MMM-InfoCentral/remote_control.html

================================================

WHAT TO EXPECT
--------------

Response JSON:
{
  "success": true,
  "button": "next",
  "message": "Next image button pressed"
}

Console Log:
[MMM-InfoCentral] HTTP NEXT button triggered

Screen Behavior:
- Next: Shows first image or advances to next
- Return: Goes back to main Magic Mirror screen

================================================

FIND YOUR PI'S IP ADDRESS
-------------------------

On Raspberry Pi:
hostname -I

Or check your router's DHCP client list

================================================

TROUBLESHOOTING
---------------

✗ Cannot connect
  → Check IP address and port (default 8080)
  → Ensure MagicMirror is running

✗ 404 Not Found
  → Module may not be loaded in config.js
  → Restart MagicMirror after installing module

✗ Access Denied
  → Update ipWhitelist in config.js
  → Allow your device's IP range

✗ Nothing happens on screen
  → Ensure images exist in images/ folder
  → Check console for errors
